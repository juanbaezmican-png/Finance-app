# Mis Finanzas

App web de finanzas personales en un único archivo (`index.html`). No hace falta instalar nada: ábrela en el navegador del móvil o del ordenador.

- Movimientos (gastos e ingresos) con categorías, método de pago, cuenta y pocket
- Gastos fijos y suscripciones que se apuntan solos cada mes
- Resumen mensual, comparación con el mes anterior y gráficos
- Presupuestos por categoría con avisos, pockets de Revolut y objetivos de ahorro
- Exportar a CSV (Excel) y copia de seguridad en JSON
- Widget para iPhone mediante la app Scriptable

Los datos se guardan en el navegador (`localStorage`), no en este repositorio.
